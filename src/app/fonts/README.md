# Inter

`inter-latin-variable.woff2` is the unmodified Inter Latin variable font
(weights 100–900, normal style), retained from the site's Google Fonts build.
It is bundled here and loaded with `next/font/local` so development and
production builds do not require Google Fonts access.

Inter is by Rasmus Andersson: https://rsms.me/inter/
